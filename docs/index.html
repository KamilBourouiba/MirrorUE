Mouse, trackpad, keyboard on silicon you own.

Tap and swipe on the mirrored surface. Auto keyboard layout translation when Mac ≠ iPhone. Dock for Home, Lock, volume, screenshot, settings.

Record demos with show-touches.

Screenshot and HEVC recording to Desktop. Touch indicators for tutorials and QA. Performance panel with fps + latency (p95).

  • Up to 120 fps
  • Diagnostics copy
