MirrorUE

Control a real iPhone from your Mac.

Native CoreMediaIO video up to 120 fps, CoreDevice HID for touch and keyboard, recording and workflows—on a development iPhone you own.

Download View source

macOS 14+ · iOS 27+ · Developer Mode · MIT

Apple’s iPhone Mirroring is not currently available in the EU, citing regulatory uncertainty around the Digital Markets Act. MirrorUE exists as a developer tool for phones you pair yourself—not a drop-in consumer replacement.

Control

Mouse, trackpad, and keyboard on the real device.

Tap and swipe on the mirrored surface. Type with automatic keyboard-layout translation when Mac and iPhone layouts differ. Dock controls for Home, Lock, volume, and more.

  • USB CoreMediaIO path (QuickTime-class capture)
  • Network CoreDevice tunnel for HID
  • Auto FR / US / DE keyboard mapping
  • Landscape digitizer remap

Present

Record demos with touch indicators.

Screenshot and HEVC screen recording to the Desktop. Optional show-touches for tutorials, QA, and livestreams. Performance panel with fps and latency.

  • ⌘⇧S screenshot · ⌘⇧R record
  • Show touches for demos
  • Target 120 fps on ProMotion Macs
  • Copy diagnostics for bug reports

Automate

Record workflows. Replay. Script via HTTP.

Capture taps, swipes, and typing into JSON workflows. Replay from the app or drive the device from a loopback API—ideal for QA smoke tests on physical hardware. 

./tools/mirrorue-cli tap 0.5 0.8
./tools/mirrorue-cli type 'hello@example.com'
./tools/mirrorue-cli run ./login.json
