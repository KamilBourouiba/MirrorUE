MirrorUE

Control a real iPhone
from your Mac.

Native video up to 120 fps. Touch, keyboard, recording, and automation— on a development iPhone you own.

Download View on GitHub ›

macOS 14+ · iOS 27+ · Developer Mode · MIT

Apple’s iPhone Mirroring isn’t currently available in the EU due to Digital Markets Act uncertainty. MirrorUE is a developer tool for phones you pair yourself—not a consumer replacement.

Control

Mouse, trackpad, and keyboard on the real device.

Tap and swipe on the mirrored surface. Type with automatic layout translation when Mac and iPhone keyboards differ. Dock controls for Home, Lock, and volume.

  • USB CoreMediaIO capture
  • CoreDevice HID tunnel
  • FR / US / DE keyboard map
  • Landscape digitizer remap

Present

Record demos with touch indicators.

Screenshot and HEVC recording to the Desktop. Optional show-touches for tutorials and QA. Performance panel with fps and latency.

  • ⌘⇧S screenshot · ⌘⇧R record
  • Show touches for demos
  • Up to 120 fps on ProMotion
  • Copy diagnostics

Automate

Record workflows. Replay. Script via HTTP.

Capture taps, swipes, and typing into JSON. Replay in-app or drive the device from a loopback API—ideal for smoke tests on physical hardware. 

$ ./tools/mirrorue-cli tap 0.5 0.8
$ ./tools/mirrorue-cli type 'hello@example.com'
$ ./tools/mirrorue-cli run ./login.json
