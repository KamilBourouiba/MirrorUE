Apple’s iPhone Mirroring isn’t currently available in the EU (DMA uncertainty). MirrorUE is a developer tool for phones you pair yourself— not a consumer replacement.

// control

Mouse, trackpad, keyboard on silicon you own.

Tap and swipe on the mirrored surface. Auto keyboard layout translation when Mac ≠ iPhone. Dock for Home, Lock, volume.

  • USB CoreMediaIO
  • CoreDevice HID
  • FR / US / DE map
  • Landscape remap

// present

Record demos with show-touches.

Screenshot and HEVC recording to Desktop. Touch indicators for tutorials and QA. Performance panel with fps + latency.

  • ⌘⇧S / ⌘⇧R
  • Show touches
  • Up to 120 fps
  • Diagnostics copy

// automate

Workflows + loopback API.

Record taps, swipes, typing to JSON. Replay in-app or script physical-device smoke tests over 127.0.0.1. 

$ ./tools/mirrorue-cli tap 0.5 0.8
$ ./tools/mirrorue-cli type 'hello@example.com'
$ ./tools/mirrorue-cli run ./login.json
